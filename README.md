## Deskripsi Game
Pemain mulai dari titik S di pojok kiri atas.
Kumpulkan semua koin ($) untuk membuka pintu keluar (E).
Jika koin belum habis, pintu akan terkunci.

## Cara Bermain
- W / Panah Atas: ke atas
- S / Panah Bawah: ke bawah
- A / Panah Kiri: ke kiri
- D / Panah Kanan: ke kanan
- P: Pause
- Q: Kembali ke menu

## Fitur Progres 1
- Menu Utama: START, HOW TO PLAY, EXIT
- Pergerakan WASD / Arrow Key
- Tabrakan dinding
- Sistem koin (+10 poin)
- Pintu terkunci jika koin belum habis

## PENJELASAN
- # : Dinding
- . : Jalan
- $ : Koin
- P : Pemain
- E : Pintu keluar
